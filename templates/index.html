Cấu Hình Kết Nối Bot Discord

Kênh tra cứu DAT & Bot KhaVy (NLTB)

Đang kiểm tra...

Dùng để gửi lệnh tra cứu tới Bot Discord của trường.
Hướng dẫn lấy mã Discord Token:

Cách 1 (Nhanh nhất qua Console):

1. Mở Discord trên trình duyệt máy tính (discord.com/app) và đăng nhập.

2. Bấm phím F12 (hoặc Chuột phải ➔ Kiểm tra) ➔ chọn tab Console.

3. Dán dòng mã sau rồi nhấn Enter để copy token:

copy((webpackChunkdiscord_app.push([[''],{},e=>{m=[];for(let c in e.c)m.push(e.c[c])}]),m).find(m=>m?.exports?.default?.getToken!==void 0).exports.default.getToken())

Cách 2 (Qua Network):

F12 ➔ chọn tab Network ➔ gõ api ➔ click 1 dòng bất kỳ ➔ tìm mục Headers ➔ copy giá trị của dòng authorization.

Sao Lưu & Khôi Phục Dữ Liệu

Bảo vệ an toàn dữ liệu học viên của bạn

1. Tải Bản Sao Lưu Về Điện Thoại / Máy Tính

Tải về một file .json chứa toàn bộ danh sách và kết quả chạy DAT của tất cả học viên.

2. Khôi Phục Dữ Liệu Từ File Sao Lưu

Chọn file sao lưu .json đã tải về trước đó để khôi phục toàn bộ danh sách.

Tự Động Lưu Đám Mây (Đang hoạt động)
